# Loom

Loom 是一款 macOS 原生窗口管理工具，支持自定义布局、悬浮操作面板与全局快捷键。**窗口随心，布局从容**，快速调整窗口位置与大小，让多窗口工作更顺滑。

Loom is a native window manager for macOS.\
Arrange windows, with ease.\
Custom layouts, popover panel & global hotkeys for your desktop workflow.

## 快速开始

Loom 支持 macOS 14 及更新版本，原生多窗口排布需要 macOS 15 及更新版本。

1. 构建应用，将 `dist/Loom.app` 复制到 `/Applications` 后打开。构建方法见下方说明。
2. 首次打开时点击“前往授权”，在 **系统设置 → 隐私与安全性 → 辅助功能** 中开启 Loom。
3. 授权成功后，将鼠标停在当前窗口的绿色按钮上，通过悬浮面板调整布局；也可以使用菜单栏图标或全局快捷键。

选择“稍后设置”后，仍可打开并编辑 Loom 设置。需要授权时，前往 **Loom → 设置 → 权限 → 前往授权**。

## 功能

### 窗口调整

- **分屏布局**：将当前窗口放到屏幕的左半、右半、上半或下半区域。
- **最大化与居中**：填满可用桌面，或保持当前大小并居中。
- **还原**：回到本次运行中 Loom 首次调整该窗口前的位置与大小。
- **移至下一显示器**：在显示器之间移动窗口，并按可用区域比例调整位置。
- **整个屏幕**：进入 macOS 原生全屏空间，与桌面最大化分别提供。

窗口布局使用屏幕的可用区域，避开菜单栏与 Dock。连续调整同一窗口时，“还原”保留最初的记录；退出 Loom 后记录清除。

### 绿点悬浮面板

将鼠标停在前台窗口的绿色按钮上，即可选择窗口布局。面板出现后保持显示，选择布局、点击空白处或按 Esc 关闭，原应用窗口保持激活。

在 **设置 → 悬浮面板** 中可以：

- 开启或关闭绿点悬浮面板。
- 调整悬停延迟与图标大小。
- 在 **10 列 × 6 行**的布局预览中拖拽图标；拖到已有图标的格子时交换位置。
- 点击图标，通过“隐藏”或“显示”调整面板内容。隐藏的图标在编辑器中置灰。
- 恢复默认布局，保留快捷键、主题等其他设置。

布局修改即时保存。实际面板只显示可见图标所在的区域，裁掉外围空行空列，保留内部空格与图标的相对位置；全部隐藏时不显示面板。

弹出前按住 Command 可使用系统绿点菜单。Loom 会检测系统菜单并避免同时显示两个面板；不同应用的标题栏与辅助功能支持可能影响触发行为。

### 网格框选

适合非常规比例的单窗口布局。在菜单栏或悬浮面板中点击“网格框选”，在目标窗口所在显示器上手动选择区域：

1. 激活后，鼠标所在格子立即显示白色选框，带滚动虚线边框。
2. 按住鼠标拖拽，扩展选区；松开后，当前窗口匹配选区的位置与大小。
3. 单击并松开可应用一格大小；按 Esc 或右键取消。

在 **设置 → 悬浮面板 → 网格框选设置** 中选择行列数，默认 **12 列 × 8 行**，可选 4、8、12……60。框选网格与图标摆放网格相互独立。

框选只调整原目标窗口，不自动排布其他窗口。反向拖拽与边缘选择会吸附到网格；成功调整后可使用“还原”。切换应用或显示器配置变化会取消框选，虚线动画遵循系统“减少动态效果”设置。

### 原生多窗口排布

提供四种系统布局：

| 布局 | 对应的 macOS 命令 |
| --- | --- |
| 双窗口左右排布 | 左侧与右侧 |
| 双窗口上下排布 | 顶部与底部 |
| 三窗口排布 | 左侧与四等分 |
| 四窗口排布 | 四等分 |

Loom 调用目标应用 **窗口 → 移动与调整大小** 中的原生命令，由 macOS 选择其他窗口并执行桌面平铺，遵循系统平铺设置。这些操作不会进入全屏 Split View。

需要 macOS 15 及更新版本、辅助功能权限，以及目标应用提供对应菜单命令。可通过菜单栏、悬浮面板或自定义快捷键使用。原生排布的恢复由系统“恢复上一个大小”负责，Loom 的“还原”只处理自身记录的普通窗口调整。

### 设置与外观

- 自定义或清除全局快捷键。
- 选择浅色、深色或跟随系统主题。
- 菜单栏显示图标，或图标与应用名称。
- 按需开启开机自启动，默认关闭。

## 默认快捷键

以下操作使用 **Control + Option** 作为修饰键：

| 操作 | 快捷键 |
| --- | --- |
| 左半屏 | ⌃⌥← |
| 右半屏 | ⌃⌥→ |
| 上半屏 | ⌃⌥↑ |
| 下半屏 | ⌃⌥↓ |
| 最大化 | ⌃⌥Return |
| 居中 | ⌃⌥C |
| 还原 | ⌃⌥Backspace |
| 移至下一显示器 | ⌃⌥N |

网格框选、原生多窗口排布与整个屏幕默认不绑定快捷键，可在 **设置 → 快捷键** 中录制。按 Esc 取消录制；清除快捷键后仍可通过菜单栏使用对应操作。快捷键冲突或注册失败时会提示并保留原配置。

## 权限与使用边界

Loom 使用辅助功能权限获取窗口位置、大小与系统菜单信息，并执行窗口调整，不读取窗口内容。应用无需账户，设置保存在本机。

- **首次引导**：只在首次启动出现；关闭或选择稍后设置后不再自动弹出。其他未授权操作使用原生提醒弹窗，权限页的按钮直接打开系统辅助功能设置。
- **悬浮面板**：未授权时显示关闭。首次授权成功后默认开启，无论从哪个入口授权；用户主动关闭后会保存选择，重新授权不会自动开启。主动重新开启时，如未授权，会先引导授权。
- **授权后继续操作**：不会自动重放授权前选择的布局，请返回目标窗口重新选择。
- **尺寸限制**：窗口能缩到多小由目标应用决定。部分应用受侧栏、额外面板或最小尺寸限制，无法完全匹配半屏或选区；此类情况保留应用接受的尺寸，不弹出尺寸限制提示。
- **窗口支持**：不可调整大小的窗口、系统全屏窗口及未提供标准辅助功能接口的窗口，部分操作可能不可用。
- **多屏与还原**：显示器按从左到右、同列从上到下循环；断开显示器后，还原位置会限制在当前可用屏幕内。

悬浮面板使用 AppKit 原生材质与自定义外壳，外观会受到 macOS 版本、主题、背景与系统透明度设置影响。

## 构建与运行

需要完整 Xcode，完成首次初始化并通过 `xcode-select` 选用，同时保证 Swift 编译器与 macOS SDK 匹配。

在项目目录中运行：

```sh
./scripts/build.sh
open dist/Loom.app
```

构建产物为本机架构的 `dist/Loom.app`，使用临时签名，适合本地开发与个人使用。建议将应用放在固定路径后再授予辅助功能权限并开启登录启动。移动应用或重新构建后，系统可能要求重新授权。

如需指定 SDK：

```sh
LOOM_SDK=/path/to/MacOSX.sdk ./scripts/build.sh
```

本项目当前开发环境可使用：

```sh
LOOM_SDK=/Library/Developer/CommandLineTools/SDKs/MacOSX15.4.sdk ./scripts/build.sh
```

日常使用应启动完整应用包。`swift run` 不适合验证辅助功能权限与登录启动；修改源码后需要重新构建并重启应用，运行中的版本不会自动更新。

### 本地测试版 DMG

在项目目录运行以下命令，会先构建应用，再生成压缩的只读磁盘映像：

```sh
./scripts/package-dmg.sh
```

需要指定 SDK 时：

```sh
LOOM_SDK=/Library/Developer/CommandLineTools/SDKs/MacOSX15.4.sdk ./scripts/package-dmg.sh
```

版本号从应用的 `Info.plist` 自动读取。当前输出为 `dist/Loom-1.0.0.dmg`，同时生成 SHA-256 校验文件。安装窗口为 600×400 pt 内容区，左侧是 Loom，右侧是指向 `/Applications` 的快捷方式，中间显示拖拽方向箭头，底部显示 slogan。Loom 使用应用包内的现有图标，Applications 使用系统图标；背景素材与 Finder 布局配置作为隐藏文件随映像打包。

打开后，将 Loom 拖到 Applications，推出映像，再从应用程序目录启动并授权。覆盖已有安装前先退出 Loom。重新安装不会清除本机的设置与首次引导状态。

打包时会临时挂载可写映像，通过 Finder 保存窗口尺寸、背景与图标位置，再转换为只读压缩映像。首次运行可能需要允许终端控制 Finder；脚本只配置临时安装卷，不修改已有 Finder 窗口。此步骤需要已登录的 macOS 图形会话。

该包使用临时签名，未完成 Developer ID 签名和 Apple 公证，仅用于本地测试，不作为公开发布包。应用与构建机器架构相同，并非 Universal 包。打包过程不会安装应用、修改已有授权或上传文件。

### 图标与引导素材

- **应用图标**：`icon/Loom.icon`。构建时通过 Xcode 的 `actool` 编译，打包 `Assets.car` 和兼容旧系统的 `Loom.icns`，保留图标文档的原生渲染设置。
- **菜单栏图标**：`icon/顶部菜单栏图标.svg`。构建时转为矢量 `MenuBarTemplate.pdf`，以模板图像适配明暗背景。
- **首次引导素材**：`Sources/Loom/Resources/Onboarding/`。本地 SVG 在构建时导出为透明 PNG，无需运行时下载。

修改素材后重新构建。构建脚本会刷新应用注册；Finder 或系统设置可能仍需重新打开才能更新图标缓存。

独立检查脚本覆盖布局计算、网格选择、悬浮面板配置、授权状态及原生命令匹配等逻辑。可按修改范围运行对应脚本，例如：

```sh

./scripts/test-palette.sh
./scripts/test-palette-layout.sh

./scripts/test-window-frame-adjustment.sh

```

上述脚本同样支持通过 `LOOM_SDK` 指定 SDK。工具链完整且版本匹配时，也可运行 `swift test`。

自动化检查不能替代真实桌面的跨应用验证。发布前重点检查：

- Safari、Finder 与常用应用的半屏、最大化、居中及连续调整后的还原。
- 绿点悬浮、系统菜单互斥、拖拽布局与网格框选的确认和取消。
- 原生双窗口、三窗口、四窗口排布，以及应用最小尺寸限制。
- 多显示器、不同缩放比例、Dock 位置变化与外接屏断开。
- 首次授权、稍后设置、权限撤销与重新授权。
- 快捷键冲突、清除与重启恢复，以及开机自启动。
